# TC-002: Link and discriminate finite protocol structure

## Description

Verify exact typed identity across every static/runtime/communication subject,
causal control, joins, bounded iteration, termination, channel premises, and
choice ownership/visibility across the selected finite representation.

## Test Procedure

Generate valid split-shipment protocols and every permitted branch interleaving.
Independently substitute definition, role-instance, workflow-instance,
participant, component, endpoint, channel, message, send, receive, delivery,
attempt, and effect identities. Add duplicate role authority; unresolved,
ambiguous, wrong-kind, and name-only references; missing join inputs, invalid
joins, cycles, missing iteration maxima, zero-progress loops, unreachable
termination, and missing/conflicting sender, receiver, message-type, order, and
delivery premises. Make choices ownerless, multiply owned, unlabeled,
overlapping, and invisible to their owner. Independently change a branch, join
rule, iteration maximum, channel premise, and visibility premise, then permute
equal-time input and presentation text.

## Expected Results

Valid structures link to identical semantic graphs. Each invalid mutation
returns the exact located refusal with no linked representation. Every authored
semantic change changes protocol identity, while presentation permutations add
no causal edge or semantic change.
